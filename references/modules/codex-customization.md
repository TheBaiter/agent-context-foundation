# Codex Customization Module

Read only when the user explicitly wants reusable Codex personalization for the repository.

Customization should be short and should point to the repository's active instruction entrypoint.

Include only durable high-level behavior:

- follow the active repository instruction route,
- read only task-relevant context,
- use the project's task system for meaningful work traceability,
- preserve canonical ownership,
- promote only verified reusable knowledge,
- follow project-specific policies rather than inventing universal Git or approval rules.

Do not copy the entire foundation into customization.

Use `references/templates/codex-customization.md`.
